## 🚀 Featured Projects

### 01. MediQueue — Clinic Appointment & Queue Management

**MERN • MongoDB • JWT • RBAC • REST APIs • Rate Limiting**

A clinic appointment and queue management system designed around reliable booking, role-based access, and real-time queue handling.

**Engineering Highlights**

* 🔒 **Race-Safe Booking** — protects appointment slots against conflicting bookings.
* 👥 **Role-Based Access** — separate Patient, Staff and Doctor workflows.
* ⏱️ **Dynamic Queue System** — calculates queue position and estimated waiting time from appointment data.
* 🛡️ **Security Controls** — Helmet, bcrypt password hashing, JWT authentication and rate limiting.
* 🧪 **Automated Testing** — comprehensive end-to-end API test coverage.

**Repository:**
https://github.com/kaurmoni0013/MediQueue

**Live Demo:**
https://mediqueue-1cu4.onrender.com

### 02. Orbit AI — Full-Stack AI Conversation Workspace

**React • Node.js • Express.js • MongoDB • Redis • OpenRouter • SSE • Docker**

A full-stack AI conversation platform focused on real-time streaming, usage control, and reliable backend processing.

**Engineering Highlights**

* ⚡ **SSE Streaming** — real-time AI response streaming with connection handling.
* 🚦 **Redis-Based Quota Control** — manages estimated token usage before upstream requests.
* 🔁 **Idempotency** — prevents duplicate processing and repeated operations.
* 🔐 **Concurrency Control** — short-lived Redis locks for concurrent operations.
* 💾 **Transactional Persistence** — maintains consistency between messages and user usage.

**Repository:**
https://github.com/kaurmoni0013/Orbit-AI

**Live Demo:**
[https://orbit-ai-k1m5.onrender.com/]
